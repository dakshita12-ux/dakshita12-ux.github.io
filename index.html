Case study: AgroFresh

An agricultural marketplace web application that identifies fruit type and freshness from a photo. View the code on GitHub.

ProjectAgroFresh
PlatformWeb application
FocusComputer vision, result clarity

The problem

In a marketplace, buyers and sellers judge fruit quality by eye, and that judgment is subjective and inconsistent. AgroFresh gives a consistent, instant read on both the type of fruit and whether it is fresh or rotten.

The flow

Upload photo→Preprocess image→Classify (6 categories)→Show result + confidence

The system classifies Apple, Banana and Orange images into six categories: each fruit as Fresh or Rotten. The pipeline uses Pillow and NumPy for preprocessing and a MobileNetV2 transfer-learning model for prediction.

Design decisions

Show confidence, not just a label. Every prediction is returned with a confidence score, so a person can tell a firm answer from a borderline one instead of trusting a bare verdict.
Keep the answer space small. Six clear categories keep results easy to read and act on, rather than a long list of fine-grained grades.
Find where it fails. I evaluated the model with precision, recall, F1-score and a confusion matrix to see which mistakes happen, since a wrong "Fresh" matters more to a buyer than a wrong "Rotten".
